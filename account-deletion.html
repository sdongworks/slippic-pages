1. 삭제 요청 방법

아래 이메일로 가입하신 계정 이메일 주소와 함께 삭제를 요청해 주세요. 본인 확인 후 처리해 드립니다.

요청 시 제목을 "[대장부] 계정 삭제 요청"으로 보내주시면 빠르게 확인할 수 있습니다.

또한 앱 내 설정 화면에서 등록한 양식(고객) 데이터를 개별적으로 직접 삭제할 수 있습니다.

2. 삭제되는 데이터

삭제 요청 시 다음 정보가 영구적으로 삭제되며 복구할 수 없습니다.

  • 회원 계정 정보 (이메일 주소, 암호화된 비밀번호)
  • 등록한 양식·고객 구조 데이터
  • 고객카드에서 추출된 데이터 및 처리 기록
  • 업로드된 원본 사진 (이미 7일 이내 자동 삭제되나, 잔여분 포함 즉시 삭제)
  • 구독·사용량 기록

3. 보존되는 데이터 및 보존 기간

관련 법령에 따라 아래 정보는 삭제 요청 이후에도 일정 기간 보관될 수 있습니다.

항목보존 기간근거

보존되는 정보는 해당 목적 외의 용도로 이용되지 않으며, 기간 경과 시 지체 없이 파기합니다.

4. 처리 기간

삭제 요청은 접수 후 영업일 기준 7일 이내에 처리하며, 처리 완료 시 요청하신 이메일로 결과를 안내해 드립니다.
